# Application client GUICANFLY

Ce dépôt public diffuse exclusivement l’application client.

Téléchargements officiels : [guicanfly.com/fr/download](https://guicanfly.com/fr/download).

- **Android client** : APK `guicanfly-client-…-arm64.apk` pour vos demandes, leur suivi et vos reçus.
- **iPhone** : ouvrez GUICANFLY dans Safari et ajoutez l’application web à l’écran d’accueil.

Nos applications seront disponibles très bientôt sur Google Play et l’App Store.

Les APK sont compilées localement. Chaque release contient le manifeste de mise à jour, les empreintes SHA-256 et les références de compilation. Ce dépôt distribue les packages ; il ne contient pas le code de l’application.
